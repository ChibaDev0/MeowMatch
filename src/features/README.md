# features/

โค้ดแยกตามโดเมนฟีเจอร์ — แต่ละโฟลเดอร์รวม UI components, hooks, server actions และ
ชนิดข้อมูลเฉพาะฟีเจอร์นั้น เพื่อให้แก้ไขเป็นหน่วยและทดสอบแยกได้

| โฟลเดอร์ | ขอบเขต | งานอ้างอิง |
|---|---|---|
| `auth/` | สมัคร เข้าสู่ระบบ กู้รหัสผ่าน Google OAuth onboarding | AUTH-01, AUTH-02 |
| `cats/` | เพิ่ม/แก้ไข/ลบแมว รูปภาพ จำนวนแมว | CAT-01, MEDIA-01 |
| `discovery/` | listing projection ตัวกรอง pagination | DISC-01 |
| `favorites/` | กดใจ/ยกเลิก และรายการในหน้าแมวที่ต้องการ | FAV-01 |
| `goals/` | บันทึกแมวตั้งต้นและเป้าหมายลักษณะลูก | GOAL-01, TARGET-01 |
| `analysis/` | หน้าผสมพันธุ์และผลวิเคราะห์ (เรียก engine ผ่าน server) | PAIR-01, TARGET-01 |
| `profile/` | โปรไฟล์ ความเป็นส่วนตัว ออกจากระบบ ลบบัญชี | PRO-01 |

UI ที่นี่ **ห้ามคำนวณ probability เอง** — เรียกผลจาก engine ผ่านชั้น server เท่านั้น

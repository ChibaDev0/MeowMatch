# MeowMatch — ขอบเขตโปรเจกต์ (probability experiment)

อัปเดต: 2026-10-13 · เอกสารนี้เป็น **แหล่งอ้างอิงหลัก** เรื่องขอบเขตและทิศทางของโปรเจกต์
ทับความเข้าใจเดิมที่ผูกกับ "DNA / ผู้เชี่ยวชาญ / การตรวจรับทางพันธุกรรม"

## โปรเจกต์นี้คืออะไร

MeowMatch เป็น **โปรเจกต์ทดลองความน่าจะเป็น (probability experiment)** สำหรับการจับคู่ผสมพันธุ์แมว
เป้าหมายเดียวคือ:

> จากลักษณะลูกแมวที่ผู้ใช้อยากได้ → **บอกว่าต้องใช้แมวที่มีลักษณะแบบไหนมาผสม**
> และ **แสดงความเป็นไปได้ (ความน่าจะเป็น)** ของลักษณะที่ลูกจะได้

แค่ "บอกความเป็นไปได้" ก็พอ — ไม่ต้องยืนยันผลจริงทางคลินิก

## สิ่งที่ **ไม่ใช่** (ตัดออกแล้ว)

โปรเจกต์นี้ **ไม่** ต้องใช้ DNA หรือยีนจริงของสัตว์ และ **ไม่** ต้องให้ผู้เชี่ยวชาญตรวจรับ
สิ่งต่อไปนี้ถูกตัดออกจากขอบเขตและลบเอกสารทิ้งแล้ว:

- ❌ การนำเข้า/ยืนยันผล DNA และ consent การใช้ข้อมูล DNA
- ❌ การตรวจรับของผู้เชี่ยวชาญ (เดิมคือ **RES-01**) และแพ็กเกจขออนุมัติ 19 ข้อ (EX-W/EX-G/CP)
- ❌ การ "ปลดล็อกเปอร์เซ็นต์พันธุกรรมจริง" หลังผู้เชี่ยวชาญลงนาม
- ❌ แผนระยะ 7 ที่ต้องมี prior/CPT ที่ผู้เชี่ยวชาญรับรอง (Bayesian/DP/Monte Carlo เป็นผลจริง)

> โค้ดวิจัยของอัลกอริทึมระยะ 7 (`src/research/genetics/`) ยังเหลืออยู่ในฐานะ **ของทดลองที่ไม่ได้ใช้งาน**
> ไม่ได้ต่อเข้าแอป ไม่อยู่ในขอบเขตปัจจุบัน และไม่จำเป็นต้องมีผู้เชี่ยวชาญมาเกี่ยวข้อง

## สิ่งที่เหลือ (ขอบเขตจริง)

1. **เก็บข้อมูลแมว** — รูปลักษณ์ (phenotype) ของแมวแต่ละตัว ตามหมวด trait
2. **หน้าหาคู่ (pair)** — เลือกแมวสองตัว → แสดงความน่าจะเป็นของลักษณะลูกรายหมวด
3. **หน้าเป้าหมาย (target / desired-cats)** — ระบุลักษณะลูกที่อยากได้ →
   - **บอกสเปกของคู่ที่ต้องใช้** (mate-spec): ต้องหาแมวที่มีลักษณะแบบไหนมาผสม
   - แสดงระดับโอกาสเบื้องต้น พร้อมเหตุผลสั้น ๆ รายลักษณะ
4. **หน้าเป้าหมายประเมินระดับโอกาสแบบเดโม** จากลักษณะภายนอก (ดูหัวข้อถัดไป)

## ผลลัพธ์หน้าแมวที่ต้องการ (ปรับ 2026-10-13)

หน้าเป้าหมายแสดงเฉพาะ **พันธุ์ สีตา ขน และหูของคู่ที่ควรหา** พร้อมระดับโอกาสเบื้องต้น
จากกติกาเดโมเทียบลักษณะภายนอก ไม่มีชุดยีน การขอผล DNA การตรวจรับ แผนหลายครอก
หรือการรับประกันลูกตรงเป้า 100% ในผลลัพธ์นี้

- เลือกคู่ที่มีลักษณะตรงกับเป้าหมายที่ผู้ใช้ระบุ
- ตั้งต้นและคู่ที่แนะนำตรงเป้าหมายเหมือนกัน → ระดับสูง
- ตั้งต้นต่างจากเป้าหมาย แต่คู่ที่แนะนำตรงเป้าหมาย → ระดับปานกลาง
- ข้อมูลตั้งต้นไม่ครบ → ข้อมูลไม่พอ พร้อมระบุว่าขาดลักษณะใด ไม่แทนด้วยศูนย์
- ภาพรวมสูงเมื่อทุกลักษณะที่เลือกเป็นระดับสูง มิฉะนั้นปานกลาง; ถ้าขาดข้อมูลให้แสดงข้อมูลไม่พอ
- ถ้าแมวตั้งต้นหูพับ แนะนำคู่หูตั้งตามเงื่อนไขเดโมไม่จับคู่หูพับกับหูพับ
- หมวดที่ไม่เลือกแสดงไม่จำกัด และไม่ส่งผลต่อระดับภาพรวม

ระดับเหล่านี้เป็นกติกาเปรียบเทียบเพื่อการสาธิต ไม่ใช่ความถี่การเกิดที่วัดจริง
จึงไม่แปลงคะแนนความเหมือนเป็นเปอร์เซ็นต์ลูกแมว

ใช้ข้อมูลพันธุ์ สีตา ขน และหูที่บันทึกไว้ของแมวตั้งต้นโดยตรง
เป้าหมายทั้งสี่ยังคงบันทึกผ่านปุ่มบันทึกเป้าหมาย
เปลี่ยนแมวหรือเป้าหมายแล้วล้างผลเก่า รวมถึงป้องกันผลคำขอเก่าทับค่าที่เพิ่งแก้

แต่ละช่องมีคำอธิบายลักษณะที่ควรเลือกและจุดที่ควรสังเกต เมื่อเชื่อม Gemini Flash
เซิร์ฟเวอร์อ่านคำสั่งจาก `docs/ai/gemini-flash.md` เฉพาะส่วนที่เกี่ยวข้องและขอบเขตส่วนนี้ก่อนเรียก API
Gemini ขยายคำอธิบายเท่านั้น ไม่เปลี่ยนสเปกคู่หรือระดับโอกาสของระบบ
หากยังไม่ตั้งค่าหรือบริการตอบไม่ได้ ใช้คำอธิบายพื้นฐานรายลักษณะที่มีอยู่ในแอป

เส้นทางใช้งาน: features/goals/desired-planner → server/analysis/appearance-action → domain/demo/appearance
ตรวจว่าแมวตั้งต้นเป็นของผู้ใช้ก่อนคำนวณเสมอ ไม่ใช้ประวัติการคำนวณทางพันธุกรรมเดิม
การเปลี่ยนนี้ครอบคลุมหน้าแมวที่ต้องการ; หน้าวิเคราะห์คู่ใช้ผลลัพธ์ใหม่ตามหัวข้อถัดไป ส่วนเครื่องมือวิจัยยังแยกอยู่
แท็บแมวที่กดใจยังคงใช้ได้ แต่ผลลัพธ์ใหม่นี้เป็นสเปกคู่ ไม่ใช่อันดับแมวที่กดใจ

## ผลลัพธ์หน้าผสมพันธุ์ (ปรับ 2026-10-13)

- เลือกแมวสองตัว แล้วอ่านข้อมูลล่าสุดฝั่งเซิร์ฟเวอร์: ตัวแรกต้องเป็นของผู้ใช้ ตัวที่สองเป็นของผู้ใช้หรือแมวที่กดใจ
- แสดงชื่อ พันธุ์ เพศ สีขน ลวดลาย ความยาวขน สีตา และหูของทั้งคู่ที่นำมาวิเคราะห์
- เพิ่มสีขนและลายขนในฟอร์มเพิ่ม/แก้ไขแมวและฐานข้อมูล ช่องเก่าไม่มีข้อมูลให้เป็นค่าว่าง ไม่เดาจากพันธุ์หรือรูป
- แสดงลักษณะลูกแยกห้าหมวด พร้อมเงื่อนไข ไม่มีคะแนนความเหมือนแปลงเป็นเปอร์เซ็นต์
- ช่วงเปอร์เซ็นต์ใช้เฉพาะแบบจำลองขนสั้น/ขนยาวเดิม ไม่ใช่การรับรองลูกจริง
- กลุ่มสีดำ/ส้มที่ระบุชัดและทราบเพศทั้งคู่ ใช้กฎอย่างง่ายแยกเพศลูก ไม่ให้ AI สลับความสัมพันธ์พ่อแม่ ไม่แจกเปอร์เซ็นต์ และไม่ครอบคลุมสีถูกบัง/เฉดจาง/กรณีพิเศษ
- หมวดสีอื่น ลายขน และสีตา ให้ Gemini อธิบายความเป็นไปได้แบบมีเงื่อนไข ความครบและรูปแบบข้อความไม่ได้รับรองความถูกต้องทุกประโยค
- ข้อมูลขาดแสดงหมวดที่ยังประเมินไม่ได้ ไม่ให้ AI เติมข้อมูลพ่อแม่ที่ไม่มี
- หูพับแสดงข้อควรพิจารณาครั้งเดียว ผลรูปลักษณ์ไม่ใช่การชักชวนผสมพันธุ์; เพศเดียวกันปฏิเสธการวิเคราะห์คู่
- เปลี่ยนคู่แล้วล้างผล รวมถึงไม่รับผลคำขอเก่าที่กลับมาทีหลัง

เส้นทาง: breeding-picker → pair-appearance-action → domain/demo/pair-appearance + pair-gemini
หน้าใหม่นี้ไม่ส่งผลเข้า history/replay ของ engine เดิม และไม่ได้แก้ข้อกำหนดของเครื่องมือวิจัย
รายละเอียดการตั้งค่าและผลทดสอบอยู่ที่ `docs/ai/pair-setup.md`

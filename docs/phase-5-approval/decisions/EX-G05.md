## ประเด็น

หากไม่มีข้อมูลรับรองให้ปิดโหมด ไม่ตั้ง prior เท่ากันเอง และไม่ขยาย scope อัตโนมัติ

ข้อเสนอ: ใช้ตารางและข้อจำกัดใน [แฟ้มหลักฐานเดิม](../../phase-5-expert-evidence.md); สถานะการนำไปทำซอฟต์แวร์ดู [รายงานรอบนี้](../README.md)

## สิ่งที่ต้องได้รับ

Bayesian prior / หลายรุ่น; ไม่เป็นเงื่อนไขเปิด single-locus demo

ผู้รับผิดชอบตามบทบาท: นักพันธุศาสตร์แมว + ผู้ตรวจแล็บ

เกณฑ์ตรวจรับ: ตรวจแฟ้ม ruleset, variant/assay manifest, fixtures และขอบเขตที่ไม่รองรับก่อนเปิดกฎจริง

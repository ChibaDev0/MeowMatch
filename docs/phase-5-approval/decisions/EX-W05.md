## ประเด็น

ต้องตรวจสุขภาพ อายุ สถานะทำหมัน ประวัติการสืบพันธุ์ หรือความเกี่ยวดองอะไรบ้างใน release นี้?

ข้อเสนอ: ใช้ตารางและข้อจำกัดใน [แฟ้มหลักฐานเดิม](../../phase-5-expert-evidence.md); สถานะการนำไปทำซอฟต์แวร์ดู [รายงานรอบนี้](../README.md)

## สิ่งที่ต้องได้รับ

รายการ required/optional/not-covered, เกณฑ์และหน่วย, แหล่งหลักฐาน, ผู้ตรวจ และอายุของข้อมูล

ผู้รับผิดชอบตามบทบาท: สัตวแพทย์ด้านสวัสดิภาพ/การสืบพันธุ์ + นักพันธุศาสตร์ตามเรื่อง + product owner

เกณฑ์ตรวจรับ: ไม่สร้างตัวเลข threshold เอง; missing/stale data ให้สถานะตามที่รับรอง; hard constraints มาก่อนคะแนน
